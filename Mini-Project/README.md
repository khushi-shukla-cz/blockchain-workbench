# Clear Charity Chain

Blockchain-Based Transparent Charity Donation and Fund Tracking System Using Smart Contracts build this project

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
